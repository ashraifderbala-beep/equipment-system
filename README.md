# نظام إدارة صيانة المعدات - SIAC

## Equipment Maintenance Management System for SIAC Construction Company

نظام شامل متخصص لإدارة صيانة المعدات الثقيلة بشكل احترافي، مع واجهة عربية كاملة وتصميم RTL متقدم.

### المميزات الرئيسية:

1. **لوحة التحكم والتقارير** - Dashboard مع مؤشرات الأداء الرئيسية
2. **سجل التشغيل اليومي** - تسجيل ساعات التشغيل وقراءات الكيلومتر
3. **دورات الصيانة (8-Cycle System)** - نظام متقدم لتتبع صيانة الوقاية
4. **بلاغات الأعطال** - نظام تذاكر متكامل للأعطال المفاجئة
5. **تنقلات المعدات** - تتبع حركة المعدات بين المشاريع
6. **التكاليف والمخزن** - إدارة تكاليف الصيانة والقطع الغيار

### متطلبات التثبيت:

```bash
npm install
npm run dev
```

### البناء والنشر:

```bash
npm run build
npm run preview
```
